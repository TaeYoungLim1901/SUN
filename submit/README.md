# 제출 폴더 — **백업 사본이다. 여기서 업로드하는 게 아니다.**

제출은 파일 업로드가 아니다. 대회 서버가 **팀 노트북의 `/home/jovyan/submission/` 을 그대로 스냅샷**해서
제출을 만든다 (`RULES.md` §2). 사람이 하는 일은 **[경진대회] > [본선] > [제출] 의 버튼을 누르는 것 하나**다.

이 폴더는 서버에 뭐가 올라가 있는지 눈으로 확인하고 사고에 대비하는 **로컬 사본**이다.

```
code.ipynb        모델 코드 (이 파일 하나만으로 학습·추론이 다 된다)
model.pth         학습이 끝난 모델
submission.csv    test 3,868행 예측
```

## 누르기 전에

```
python tools/submit.py
```

서버에서 버그 검사 15항목을 돌리고, **통과했을 때만** 사본을 여기로 내려받는다.
「전부 통과. 제출해도 된다」가 나오면 버튼을 눌러도 된다.

⚠ **학습이나 노트북 실행이 도는 중에는 누르지 마라.** 서버는 누르는 시점의 폴더 상태를 그대로 가져간다.
`submission.csv` 를 덮어쓰는 중이면 깨진 제출이 나간다.

## 지금 서버에 올라가 있는 모델

| | validation RMSE |
|---|---|
| persistence (마지막 관측을 그대로 유지) | 87.6 |
| 대회 공식 베이스라인 (3D-CNN + LSTM) | 78.1 |
| 풍속 20개만 사용 | 75.0 |
| **현재** (영상 스칼라 피처 + GBDT 3종 결합) | **64.76** |

`code.ipynb` 를 서버에서 실제로 실행해 `submission.csv` 가 **비트 단위로 동일하게** 재현되는 것까지 확인했다.
