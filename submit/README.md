# 제출 폴더

여기 있는 파일 **3개를 그대로** 대회 사이트에 올려라. 이름을 바꾸지 마라.

```
code.ipynb        모델 코드 (이 파일 하나만으로 학습·추론이 다 된다)
model.pth         학습이 끝난 모델
submission.csv    test 3,868행 예측
```

## 파일 새로 받기

```
python tools/submit.py
```

서버에서 버그 검사를 먼저 돌리고, **통과했을 때만** 세 파일을 이 폴더로 내려받는다.
검사가 실패하면 아무것도 받지 않는다 — 깨진 파일을 올리는 게 제일 나쁜 결말이라서 그렇다.

쿠키가 만료돼서 실패하면 `CONNECT.md` 의 4단계를 다시 하면 된다 (30초).
