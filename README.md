# sungnam-to-kaist

해커톤 예선 학습 자료 — 천문우주 학습 영상의 음성 전사본.

## 왜 유튜브 자동자막을 안 썼나

자동자막을 먼저 받아서 검사했더니, 정작 퀴즈에 나올 도메인 용어만 골라서 틀려 있었다.
과학토크쇼 영상(전체 3,145자) 기준:

| 검색어 | 자동자막 등장 횟수 |
|---|---|
| **극대기** (영상 제목에 있는 단어) | **0** |
| **흑점** | **0** |
| 극소기 / 플레어 / 태양풍 | 각 0 |
| 재채기 | 0 (대신 `제책기`) |
| 자기장 | 11 |
| 오로라 | 4 |

`자기장`·`오로라` 같은 일상 어휘는 잘 잡히는데 전문 용어는 통째로 증발한다.
그래서 자동자막을 버리고 오디오에서 직접 재전사했다.

## 전사 방식

- `faster-whisper` **medium**, `int8` 양자화, **CPU 전용** (이 노트북에 전용 GPU 없음)
- `language="ko"`, `beam_size=5`, `vad_filter=True`
- `condition_on_previous_text=False` — 반복 폭주 방지
- **`initial_prompt` 미사용** — 도메인 용어를 프롬프트로 심으면 Whisper가 실제로
  나오지 않은 단어를 끼워 넣는 부작용이 있어서 뺐다. 안 넣어도 용어는 잘 잡혔다.

실측 속도는 오디오 길이 대비 **0.73~1.19배**. 총 126분 분량에 약 2시간 걸렸다.

## 알려진 한계

전사본을 그대로 신뢰하면 안 되는 지점들이다.

1. **오탈자가 남아 있다.** 팩트 자체는 대체로 정확하지만 표기가 틀린 곳이 있다.
   예: `핵룡압`→핵융합, `헬류물을`→헬륨으로, `진량`→질량, `고의도`→고위도,
   `종애의 기원`→종의 기원, `조선왕조실로`→조선왕조실록, `아마초`→아마추어.
   고유명사 표기도 흔들린다 (`로키츠/록히츠/로켓츠/럭키치`).

2. **VAD가 일부 구간을 건너뛰었다.** 과학토크쇼에서 `[08:09] → [08:54]` 45초,
   `[10:32] → [10:51]` 19초가 비어 있다. 배경음악일 수도 있고 실제 발화가
   잘렸을 수도 있다. 확인하려면 해당 파일만 `vad_filter=False`로 재전사할 것.

3. **숫자·연도는 원본 영상으로 교차 확인할 것.** 전사기가 숫자를 틀리면
   퀴즈에서 그대로 오답이 된다.

## 스크립트

| 파일 | 용도 |
|---|---|
| `transcribe.py` | 단일 오디오 전사 |
| `run_queue.py` | `audio/` 안의 미처리 파일을 짧은 것부터 순차 전사 (모델 1회 로드 후 재사용) |
| `rename_outputs.py` | 결과 파일명을 유튜브 ID → 제목으로 변경 |

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv faster-whisper
yt-dlp -f "bestaudio[ext=m4a]/bestaudio" -o "audio/%(id)s.%(ext)s" <URL>
.venv/Scripts/python.exe run_queue.py medium
```

`audio/`는 원저작물이라 `.gitignore`로 제외했다.
