## 4. 작업 방식 — 왜 이렇게 하는가

### 4.1 전체 val RMSE 로 카드를 고르지 않는다

**이게 이 대회에서 제일 비쌌던 교훈이다.** validation 과 test 는 분포가 다르다
(adversarial AUC = 1.0 — 분류기가 완벽히 갈라낸다). 그래서 전체 val RMSE 는 Public 의 대리지표로
부실하고, 실제로 **부호까지 틀린다**:

| 카드1 → 카드2 | 값 |
|---|---|
| 전체 val Δ | **+0.025 (나빠짐)** |
| bulk Δ (`\|target − wind_19\|` < p60 인 셀만) | **−0.155** |
| 실제 Public Δ | **−0.1737** |

전체 val 만 봤으면 최고 기록이 된 카드를 안 냈다. **카드 선택 지표는 bulk Δ 다** (전이비 1.12).
「bulk」= 마지막 관측 대비 변화가 작은 대다수 셀. 이긴 판은 전부 여기서 이겼고,
상위 5% 램프 셀에서는 전부 졌다 — 그 구간은 성분 전부가 RMSE 152~176 으로 비슷해서 현재 미해결이다.

### 4.2 숫자 하나로 채택도 기각도 하지 않는다

val 은 6시간 창이 겹쳐서 행이 독립이 아니다. 그래서 **연결요소 11개로 묶어서** 판정한다:

```
python work/paired.py A.npy B.npy      # 성분별 Δ 부호 + 절반분할 σ + 부트스트랩 CI
python work/bulkjudge.py               # 위를 bulk 구간에서. 카드2 를 고른 도구
python work/add_honest.py --base N50   # 가중을 반쪽에서 고르고 반대쪽에서 채점 (2-fold×20)
```

채택 조건: bulk Δ ≤ −0.15 · 성분 부호 일치 ≥ 8/11 · P(Δ<0) ≥ 0.9.
**σ 는 그 쌍에서 직접 잰다** — 다른 쌍의 σ 를 빌리면 결론이 뒤집힌다 (실제로 3번 뒤집혔다).

### 4.3 기각한 축은 재개 조건과 함께 적어 둔다

`CLOSED_AXES.md`. 새 실험 전에 여기부터 grep 한다. 지난 대회에서 닫힌 축을 5번 다시 열었다.
최근에 닫은 것 둘:

- **cnn9 에 하이브리드 몫을 통째로 주기** — 시드를 3→18 로 키워도 bulk Δ 가 양수에 머물고
  0 으로 수렴하는 추세가 없다.
- **시드백 더 굽기** — cnn7 은 8개, 광류는 16개를 넘으면 변동이 bulk σ(0.106) 아래다.
  시드는 GPU 시간을 태우는 것 말고 하는 일이 없다.
